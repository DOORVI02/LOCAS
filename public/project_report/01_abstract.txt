ABSTRACT

The "Library for College Administration System" (LOCAS) is a comprehensive software solution designed and developed to streamline, modernize, and automate the intricate daily operations of a college library. Undertaken as a core project for the Database Management System (DBMS) course at UTD-CSVTU Bhilai, LOCAS aims to replace traditional, labor-intensive manual record-keeping methods—such as physical card catalogs and paper registers—with an efficient, digital interface backed by a robust relational database.

The system facilitates a wide range of library functions including book acquisition, metadata cataloging, student and staff membership management, circulation control (issue and return processes), and financial administration for overdue fines. A critical feature of the system is its implementation of strict Role-Based Access Control (RBAC), which cleanly distinguishes between Administrators, Librarians, and Students, thereby ensuring data security, operational integrity, and appropriate access levels for sensitive information. By digitizing these processes, the system minimizes human error and substantially reduces the time required for information retrieval.

From a technical perspective, the project is engineered using Python 3.12 with PyQt6 to deliver a high-performance, native Graphical User Interface (GUI) that offers a superior user experience on desktop platforms compared to web-based alternatives. The backend is powered by MySQL 8.0, providing a structured mechanism to enforce data integrity through normalization (3NF) and foreign key constraints. Distinguishing features include the logical separation of generic Book metadata from physical Book Copies, real-time availability checking, automated fine calculation based on borrowing policies, and comprehensive audit logs that track every administrative action.

This report comprehensively documents the entire development lifecycle of LOCAS, following an Iterative Waterfall methodology. It details the journey from initial problem verification and system design—illustrated through Entity-Relationship (ER) diagrams and Data Flow Diagrams (DFD)—to the final implementation and rigorous testing phases. The resulting functional prototype serves as a testament to the practical efficacy of DBMS principles, such as ACID properties and Transaction Management, in solving real-world administrative challenges.

Keywords: Library Management System (LMS), Database Management System (DBMS), Relational Database, Python, MySQL, PyQt6, Role-Based Access Control (RBAC), Normalization, Data Integrity, Software Engineering.
